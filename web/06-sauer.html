Section 6

Sauer's Lemma

Finite VC dimension forces polynomial growth.

Theorem

Theorem (Sauer)

If $\mathrm{VCdim}(\mathcal F) \le d$, then $$\Pi_{\mathcal F}(m) \;\le\; \sum_{i=0}^{d}\binom{m}{i},$$ and for $m \ge d$, $$\Pi_{\mathcal F}(m) \;\le\; \Bigl(\frac{em}{d}\Bigr)^d.$$

Proof idea

The proof uses induction on $m + d$. Removing one point $x_1$ from the sample splits the labellings into two groups:

  • labellings with a unique extension at $x_1$,
  • labellings admitting both $\pm 1$ extensions at $x_1$.

Let $\mathcal F_1 = \mathcal F\big|_X$ (full restriction), $\mathcal F_2 = \mathcal F\big|_{X \setminus \{x_1\}}$, and $\mathcal F_3$ = the labellings in $\mathcal F_2$ that admit both $\pm 1$ extensions at $x_1$. A direct count gives $$|\mathcal F_1| = |\mathcal F_2| + |\mathcal F_3|.$$

If a subset of labellings admits both extensions, its effective VC dimension drops by one: $$\mathrm{VCdim}(\mathcal F_3) \;\le\; d - 1.$$ Reason: if $\mathcal F_3$ shattered a set of size $d$, we could add $x_1$ back and shatter a set of size $d+1$ in $\mathcal F$ — contradicting $\mathrm{VCdim}(\mathcal F) \le d$.

Applying the inductive hypothesis to $\mathcal F_2$ (sample size $m-1$, VCdim $\le d$) and $\mathcal F_3$ (sample size $m-1$, VCdim $\le d-1$), then using Pascal's identity $\binom{m}{i} = \binom{m-1}{i} + \binom{m-1}{i-1}$, gives the bound.

From sum-of-binomials to $(em/d)^d$

For $m \ge d$, multiply Sauer's bound by $(m/d)^d \cdot (d/m)^d = 1$ and use the binomial theorem: $$\sum_{i=0}^d \binom{m}{i} \le \Bigl(\frac{m}{d}\Bigr)^d \sum_{i=0}^m \binom{m}{i}\Bigl(\frac{d}{m}\Bigr)^i = \Bigl(\frac{m}{d}\Bigr)^d \Bigl(1 + \frac{d}{m}\Bigr)^m \le \Bigl(\frac{em}{d}\Bigr)^d,$$ using $(1 + d/m)^m \le e^d$.

The dichotomy

Sauer's lemma forces polynomial growth where the trivial bound was exponential: $$2^m \;\longrightarrow\; m^d.$$ That gap is what makes generalisation possible.

Critical insights

What this lemma actually says
  1. Combinatorial collapse. Failure to shatter beyond $d$ points forces polynomial rather than exponential growth.
  2. Purely combinatorial. The proof uses counting and shattering structure rather than probability or geometry.
  3. Historical importance. Sauer's lemma is one of the foundational links between combinatorics and statistical learning theory.

What's next
