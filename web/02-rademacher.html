Chapter 2

Rademacher complexity

Can the class fit pure random noise?

Rademacher random variables

A Rademacher random variable $\varepsilon$ takes values in $\{-1, +1\}$, each with probability $1/2$. We will use a vector $\varepsilon = (\varepsilon_1, \dots, \varepsilon_m)$ of i.i.d. Rademacher variables — think of them as $m$ random coin flips translated to $\{\pm 1\}$.

Why this distribution? Three reasons. (i) Symmetry: $\varepsilon$ and $-\varepsilon$ have the same distribution. (ii) Bounded: $|\varepsilon_i|=1$, ideal for concentration. (iii) Match: when our class predicts $\pm 1$, sign-valued noise pairs naturally with sign-valued predictions.

The definition

Definition — Rademacher complexity

Let $\mathcal{H}$ be a class of real-valued functions on a domain $\mathcal{Z}$. Given $m$ samples $S = (z_1, \dots, z_m)$ drawn i.i.d. from a distribution on $\mathcal Z$, the empirical Rademacher complexity is $$ \widehat{\mathfrak{R}}_S(\mathcal H) \;=\; \mathbb{E}_{\varepsilon}\!\left[\sup_{h\in\mathcal H}\frac{1}{m}\sum_{i=1}^{m}\varepsilon_i h(z_i)\right]. $$ The (population) Rademacher complexity averages this over the data: $$ \mathfrak{R}_m(\mathcal H) \;=\; \mathbb{E}_{S}\bigl[\widehat{\mathfrak R}_S(\mathcal H)\bigr] \;=\; \mathbb{E}_{S,\varepsilon}\!\left[\sup_{h\in\mathcal H}\frac{1}{m}\sum_{i=1}^{m}\varepsilon_i h(z_i)\right]. $$

What this number actually measures

Read the inner expression as a correlation. We hand the class a string of pure $\pm 1$ noise and ask: how well can some $h\in\mathcal H$ correlate with that noise on the sample? If the class is rich enough that some member can mimic any random pattern, the supremum is large. If every member is too smooth or too constrained to track the noise, the supremum is small.

Intuition

$\mathfrak{R}_m(\mathcal H)$ is the expected best-case alignment between a function from $\mathcal H$ and a string of random sign labels. Formally it lives between $0$ and $\sup_{h,z}|h(z)|$. For binary classes ($h(z)\in\{\pm1\}$) it lives in $[0,1]$.

A small worked example

Let $\mathcal Z = \mathbb{R}$ and let $\mathcal H$ be the class of constant functions $\{h(z)=c : c\in\{-1,+1\}\}$. Only two functions. For any sample,

$$ \sup_{h\in\mathcal H}\frac{1}{m}\sum_{i=1}^{m}\varepsilon_i h(z_i) = \frac{1}{m}\sup_{c\in\{-1,+1\}} c\sum_{i=1}^{m}\varepsilon_i = \frac{1}{m}\Bigl|\sum_{i=1}^{m}\varepsilon_i\Bigr|. $$

Taking expectation over $\varepsilon$ and using the standard fact that $\mathbb{E}|\sum \varepsilon_i| \le \sqrt m$, we get $\mathfrak R_m(\mathcal H) \le 1/\sqrt m$. The class is two functions, and its complexity is small. Notice it goes to $0$ as $m \to \infty$ — that is what we want for any class that generalises.

Geometric picture

Random sign labels are placed above 6 points. Rademacher complexity asks: what is the highest correlation that any $h\in\mathcal H$ can achieve with this random labelling, averaged over all sign patterns?

Why this is the "right" complexity measure

Three properties make Rademacher complexity exactly what we need.

  1. Distribution-aware. Unlike combinatorial measures that look only at $\mathcal H$, $\mathfrak R_m$ depends on the data distribution. A class that can fit noise in some weird pocket of the input space but not where mass lives still has small $\mathfrak R_m$.
  2. Bounds the gap. The next chapter shows $\mathbb{E}\sup(\widehat R - R)\le 2\,\mathfrak R_m$. So bounding $\mathfrak R_m$ is sufficient for generalisation guarantees.
  3. Composes. If you compose with a Lipschitz function (e.g. a loss like the hinge loss), the Rademacher complexity changes by at most a constant factor. This is the contraction lemma — beyond our scope but worth knowing.

An identity we will need

For binary classification with the 0–1 loss, the Rademacher complexity of the loss class equals exactly half the Rademacher complexity of the function class.

Lemma (Lecture 10, 1.1)

Let $\mathcal F \subseteq \{\pm 1\}^{\mathcal X}$ and let $\phi(y',y) = \mathbf 1[y'\ne y]$ be the 0–1 loss. Let $\phi_{\mathcal F} = \{(x,y) \mapsto \phi(f(x), y) : f\in\mathcal F\}$. Then $$ \mathfrak{R}_m(\phi_{\mathcal F}) = \tfrac{1}{2}\,\mathfrak{R}_m(\mathcal F). $$

Proof.

For $y, y' \in \{\pm 1\}$, $\mathbf 1[y'\ne y] = (1 - y\,y')/2$. Substitute:

$$ \mathfrak{R}_m(\phi_{\mathcal F}) = \mathbb{E}\!\left[\sup_{f}\frac{1}{m}\sum_{i=1}^m \varepsilon_i\,\frac{1 - Y_i f(X_i)}{2}\,\Big|\,X_1^m, Y_1^m\right]. $$

The constant $1$ inside the sum gives $\sum \varepsilon_i$ which has zero conditional mean and contributes $0$ after the expectation over $\varepsilon$. So

$$ \mathfrak{R}_m(\phi_{\mathcal F}) = \frac{1}{2}\,\mathbb{E}\!\left[\sup_{f}\frac{1}{m}\sum_{i=1}^m (-\varepsilon_i Y_i)\, f(X_i)\right]. $$

For each $i$, $-\varepsilon_i Y_i$ has the same joint distribution as $\varepsilon_i$ (because $\varepsilon_i$ is symmetric and independent of $Y_i$). Replacing $-\varepsilon_i Y_i$ by $\varepsilon_i$:

$$ \mathfrak{R}_m(\phi_{\mathcal F}) = \frac{1}{2}\,\mathbb{E}\!\left[\sup_{f}\frac{1}{m}\sum_{i=1}^m \varepsilon_i f(X_i)\right] = \frac{1}{2}\,\mathfrak{R}_m(\mathcal F). $$

Taking expectation over $X_1^m, Y_1^m$ and observing the right-hand side does not depend on $Y$ finishes the argument.

This factor of $\tfrac{1}{2}$ is why a $2$ appears in the symmetrisation theorem of the next chapter.
