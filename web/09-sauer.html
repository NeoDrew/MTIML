Chapter 9

Sauer's lemma

Finite VC dimension forces polynomial growth.

The statement

Sauer's lemma

If $\mathrm{VCdim}(\mathcal F) \le d$, then for every $m$, $$ \Pi_{\mathcal F}(m) \;\le\; \sum_{i=0}^{d}\binom{m}{i}. $$

The right-hand side is a sum of binomial coefficients up to $d$. For $d$ fixed and $m$ growing, this grows polynomially in $m$ (the dominant term is $\binom{m}{d} \sim m^d / d!$). Compare to the trivial bound $2^m$, which sums all binomial coefficients up to $m$.

This dichotomy — $\Pi_{\mathcal F}(m)$ is either always exponential ($\mathrm{VCdim} = \infty$) or eventually polynomial ($\mathrm{VCdim} = d < \infty$) — is the deepest combinatorial fact in the entire theory.

Proof sketch

The proof is by induction on $m + d$. The base case is easy. The inductive step is a clever counting argument: the labellings of $\mathcal F$ on $m$ points break into two pieces — those that can be extended both ways at one specific point, and those that can only be extended one way. Each piece is bounded by induction.

The full proof

Proof.

Define $h(m, d) = \sum_{i=0}^{d}\binom{m}{i}$. We will show $\Pi_{\mathcal F}(m) \le h(m, d)$ whenever $\mathrm{VCdim}(\mathcal F) \le d$, by induction on $m + d$.

Base case: $m = 1, d = 1$ gives $h(1,1) = \binom{1}{0} + \binom{1}{1} = 2$. The growth function $\Pi_{\mathcal F}(1) \le 2$ holds trivially.

Pascal's identity (used implicitly): $\binom{m}{i} = \binom{m-1}{i} + \binom{m-1}{i-1}$, which gives $$ h(m, d) = h(m-1, d) + h(m-1, d-1). $$

Inductive step. Fix $\mathcal F$ with $\mathrm{VCdim}(\mathcal F) \le d$ and a sample $X = \{x_1, \dots, x_m\}$. Let $X_2 = \{x_2, \dots, x_m\}$ (drop the first point). Define three function classes:

  • $\mathcal F_1 = \mathcal F\big|_X$ — the full restriction. We want $|\mathcal F_1| = $ number of label vectors achievable on $X$.
  • $\mathcal F_2 = \mathcal F\big|_{X_2}$ — restriction to the dropped sample.
  • $\mathcal F_3$ = the set of label vectors $a \in \mathcal F_2$ such that both extensions to $x_1$ are realised — that is, both $(+1, a)$ and $(-1, a)$ appear in $\mathcal F_1$.

These are subtle definitions; spend a moment with them. $\mathcal F_3$ records which "tail labellings" on $X_2$ are ambiguous at $x_1$ — both signs work.

Counting. Each label vector on $X$ is determined by its tail (in $\mathcal F_2$) plus its first coordinate. For unambiguous tails (in $\mathcal F_2 \setminus \mathcal F_3$), only one of the two first-coordinate signs is realised in $\mathcal F$, contributing $|\mathcal F_2 \setminus \mathcal F_3|$ label vectors to $\mathcal F_1$. For ambiguous tails (in $\mathcal F_3$), both signs are realised, contributing $2|\mathcal F_3|$. So $$ |\mathcal F_1| = (|\mathcal F_2| - |\mathcal F_3|) + 2|\mathcal F_3| = |\mathcal F_2| + |\mathcal F_3|. $$

Bound $|\mathcal F_2|$. Restricting to a smaller point set can only decrease the VC dimension (any set shattered by $\mathcal F_2$ is also shattered by $\mathcal F$). So $\mathrm{VCdim}(\mathcal F_2) \le d$. The sample $X_2$ has size $m-1$, so by induction (on the smaller pair $(m-1, d)$): $$ |\mathcal F_2| \;\le\; h(m-1, d). $$

Bound $|\mathcal F_3|$. We claim $\mathrm{VCdim}(\mathcal F_3) \le d - 1$. Suppose, for contradiction, that $\mathcal F_3$ shatters some set $S \subseteq X_2$ of size $d$. Every labelling of $S$ then appears as a tail in $\mathcal F_3$. By definition of $\mathcal F_3$, every such tail extends both ways at $x_1$. So in $\mathcal F$, every labelling of $S \cup \{x_1\}$ is realised — a set of size $d + 1$ is shattered. But $\mathrm{VCdim}(\mathcal F) \le d$. Contradiction. So $\mathrm{VCdim}(\mathcal F_3) \le d - 1$.

By induction (on the pair $(m-1, d-1)$): $$ |\mathcal F_3| \;\le\; h(m-1, d-1). $$

Combine. $$ |\mathcal F_1| \le h(m-1, d) + h(m-1, d-1) = h(m, d). $$ Since $X$ was arbitrary, $\Pi_{\mathcal F}(m) \le h(m, d)$.

Reading the proof

The clever bit is the definition of $\mathcal F_3$. It captures exactly the labellings on $X_2$ that "use" the freedom to flip $x_1$. If $\mathcal F_3$ shattered too many points, then together with $x_1$ those points would be shattered by $\mathcal F$ — exceeding the VC dimension.

The Pascal identity is the engine: it says the doubly-recursive count $h(m, d)$ obeys exactly the right combinatorial recurrence to absorb the two terms.

The polynomial form

The sum-of-binomials bound is sharp but unwieldy. Here is a clean closed-form for $m \ge d$:

Corollary 3.1

If $\mathrm{VCdim}(\mathcal F) \le d$ and $m \ge d$, then $$ \Pi_{\mathcal F}(m) \;\le\; \Bigl(\frac{em}{d}\Bigr)^{d}. $$

Proof.

Multiply Sauer's bound by $(m/d)^d \cdot (d/m)^d = 1$: $$ \sum_{i=0}^{d}\binom{m}{i} \le \Bigl(\frac{m}{d}\Bigr)^d \sum_{i=0}^{d}\binom{m}{i}\Bigl(\frac{d}{m}\Bigr)^i. $$ We've used $(d/m)^i \le 1$ for $i \le d$ since $d \le m$, so $(m/d)^d \cdot (d/m)^i \ge 1$ — the inequality is in the direction we want.

Extend the sum to $i = m$ (only adds non-negative terms): $$ \le \Bigl(\frac{m}{d}\Bigr)^d \sum_{i=0}^{m}\binom{m}{i}\Bigl(\frac{d}{m}\Bigr)^i = \Bigl(\frac{m}{d}\Bigr)^d \Bigl(1 + \frac{d}{m}\Bigr)^m, $$ using the binomial theorem.

Finally use $(1 + x/m)^m \le e^x$: $$ \le \Bigl(\frac{m}{d}\Bigr)^d e^d = \Bigl(\frac{em}{d}\Bigr)^d. $$

Putting Sauer to work

Plug into Theorem 1.1: $$ \mathfrak R_m(\mathcal F) \le \sqrt{\frac{2 \ln \Pi_{\mathcal F}(m)}{m}} \le \sqrt{\frac{2\ln(em/d)^d}{m}} = \sqrt{\frac{2 d \ln(em/d)}{m}}. $$ For $m \gg d$, this scales like $\sqrt{d\ln m / m}$ — square-root in the sample size, with a logarithmic penalty.

The dichotomy, made formal

Sauer's lemma turns a soft idea ("the class can't shatter beyond size $d$") into a hard quantitative statement ("the growth function is polynomial"). It is one of the most useful combinatorial inequalities in mathematics — the same form shows up in shatter functions, Helly numbers, and other parts of discrete geometry.
