Chapter 4

Growth function

From a class of functions to a finite set of label vectors.

Restricting a class to a sample

The hypothesis class $\mathcal F$ may be infinite — even uncountable. But for the purposes of generalisation on a particular sample of size $m$, only the values $f(x_1), \dots, f(x_m)$ matter. Two functions in $\mathcal F$ that agree on the sample are indistinguishable from the data's point of view.

Definition — restriction of a class

For $\mathcal F \subseteq \{\pm 1\}^{\mathcal X}$ and a finite set of points $x_1, \dots, x_m \in \mathcal X$, the restriction of $\mathcal F$ to $x_1^m$ is the set of label vectors that members of $\mathcal F$ produce on those points: $$ \mathcal F\big|_{x_1^m} = \bigl\{\,(f(x_1), \dots, f(x_m)) : f \in \mathcal F\,\bigr\} \subseteq \{\pm 1\}^m. $$

This is a finite set, no matter how large $\mathcal F$ is, because $\{\pm 1\}^m$ has only $2^m$ elements. So

$$ \bigl|\mathcal F\big|_{x_1^m}\bigr| \;\le\; \min\bigl\{|\mathcal F|,\ 2^m\bigr\}. $$

The interesting case is when $|\mathcal F|$ is huge but the restriction is small: that means the class can only realise a limited number of patterns on these particular $m$ points, even though it has many members in total.

An example with two points

Take $\mathcal F$ to be the class of "threshold functions": $f_\theta(x) = \mathrm{sgn}(x - \theta)$ for $\theta \in \mathbb R$. There are uncountably many functions (one per real $\theta$). On a sample of two points $x_1 < x_2$, what label vectors are achievable?

  • $\theta < x_1$: both labels are $+1$. Vector $(+1,+1)$.
  • $x_1 \le \theta < x_2$: $f(x_1)=-1$, $f(x_2)=+1$. Vector $(-1,+1)$.
  • $\theta \ge x_2$: both labels are $-1$. Vector $(-1,-1)$.

That's three distinct vectors out of $2^2 = 4$ possible. The vector $(+1,-1)$ — first point positive, second negative — is impossible: any threshold high enough to make $x_2$ negative will already make $x_1$ negative. So $|\mathcal F|_{x_1, x_2}| = 3 < 4$.

That gap, between what is achievable and the maximum $2^m$, is the central object of this theory.

The growth function

Definition — growth function

The growth function of $\mathcal F$ at sample size $m$ is the maximum number of distinct label vectors $\mathcal F$ can produce on any $m$ points: $$ \boxed{\;\Pi_{\mathcal F}(m) \;=\; \max_{x_1, \dots, x_m \in \mathcal X}\,\bigl|\mathcal F\big|_{x_1^m}\bigr|.\;} $$

It is a worst-case count: we get to choose the $m$ points adversarially to maximise the diversity of labellings. The growth function is a non-decreasing, finite-valued function of $m$, with

$$ 1 \le \Pi_{\mathcal F}(m) \le 2^m. $$

Why we care about it

In the next chapter we will prove (using Massart's lemma) that

$$ \mathfrak R_m(\mathcal F) \;\le\; \sqrt{\frac{2 \ln \Pi_{\mathcal F}(m)}{m}}. $$

So the growth function controls the Rademacher complexity. If we can show $\Pi_{\mathcal F}(m)$ is much smaller than $2^m$ — say, polynomial in $m$ — we get a meaningful generalisation bound.

The trivial bound is useless

Plug in the worst-case $\Pi_{\mathcal F}(m) = 2^m$: $$ \mathfrak R_m(\mathcal F) \le \sqrt{\frac{2\ln 2^m}{m}} = \sqrt{2\ln 2} \approx 1.18. $$ This is a constant! It does not vanish as $m \to \infty$, so it cannot prove that more data improves generalisation. To get something useful, we will need $\Pi_{\mathcal F}(m)$ to grow slower than exponentially.

Many functions, one labelling

Three different functions in $\mathcal F$ that produce the same label vector $(+1, -1, +1, -1)$ on these four points. The growth function counts label vectors, not functions, so all three contribute only one element to $\mathcal F|_{x_1^4}$.

What's next

We have a finite set of label vectors. Massart's lemma — the topic of the next chapter — says that the Rademacher complexity of any finite set in $\mathbb R^m$ is at most $r\sqrt{2\ln|A|}/m$, where $r$ is the maximum norm. Combined with $\Pi_{\mathcal F}(m)$, that will give the bound we need.
