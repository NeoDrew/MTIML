Section 3

From Functions to Label Vectors

Reducing an infinite class to a finite combinatorial quantity.

Restriction to the sample

For binary classifiers $\mathcal F \subseteq \{\pm 1\}^{\mathcal X}$, the Rademacher complexity depends on $\mathcal F$ only through its restriction to the sample: $$\mathcal F\big|_{x_1^m} \;:=\; \bigl\{(f(x_1), \dots, f(x_m)) : f \in \mathcal F\bigr\} \;\subseteq\; \{\pm 1\}^m.$$ Distinct functions may collapse to the same label vector; only $|\mathcal F|_{x_1^m}| \le 2^m$ such vectors exist regardless of $|\mathcal F|$.

The growth function

Definition

The growth function is the worst-case cardinality of this restriction: $$\Pi_{\mathcal F}(m) \;=\; \max_{x_1, \dots, x_m \in \mathcal X}\,\bigl|\mathcal F\big|_{x_1^m}\bigr|.$$

From analysis to combinatorics

The complexity of an infinite class is reduced to a finite combinatorial quantity: the number of distinct label patterns realisable on $m$ points. The trivial bound $\Pi_{\mathcal F}(m) \le 2^m$ yields $$\mathfrak R_m(\mathcal F) \;\le\; \sqrt{\frac{2 \ln 2^m}{m}} \;=\; \sqrt{2 \ln 2},$$ which fails to vanish as $m \to \infty$. Establishing learnability therefore requires structural conditions ensuring $\Pi_{\mathcal F}(m) \ll 2^m$.

Key idea

Capacity is measured by distinguishable behaviours on finite samples, not by the cardinality of $\mathcal F$.

A small worked example

Let $\mathcal F$ be threshold functions $f_\theta(x) = \mathrm{sgn}(x - \theta)$, $\theta \in \mathbb R$ — uncountably many functions. On a sample of two points $x_1 < x_2$, only three label vectors are achievable:

  • $\theta < x_1$: vector $(+1, +1)$.
  • $x_1 \le \theta < x_2$: vector $(-1, +1)$.
  • $\theta \ge x_2$: vector $(-1, -1)$.

The vector $(+1, -1)$ is unrealisable. So $\Pi_{\mathcal F}(2) = 3 < 2^2 = 4$. The class is uncountable but its growth function is small.

Three different functions realising the same label vector on four points. The growth function counts label vectors, not functions.

What's next

To turn $\Pi_{\mathcal F}(m)$ into a Rademacher bound, we need a tool that converts "size of a finite set of vectors" into "expected supremum over Rademacher signs". That tool is Massart's lemma — the topic of the next section.
