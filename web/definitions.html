Definitions

Definitions, in plain English

The vocabulary of the field, with worked examples.

If a term in any chapter is fuzzy, look it up here. Each entry has the formal definition followed by one or two concrete examples.

Hypothesis class

Definition

A hypothesis class $\mathcal F$ is a set of functions from inputs $\mathcal X$ to outputs $\mathcal Y$. Every function in the set is a candidate rule that your learning algorithm could possibly return.

Almost always specified as a parametrised family — pick parameters, get a function. Vary the parameters and you sweep out the whole class.

Example 1: thresholds on the real line

$$\mathcal F = \{\, x \mapsto \mathrm{sgn}(x - \theta) \;:\; \theta \in \mathbb R \,\}.$$ Each value of $\theta$ defines one function ("$+1$ to the right of $\theta$, $-1$ to the left"). The class is the whole continuous family of those functions, one per $\theta$.

Example 2: linear classifiers (halfspaces) in $\mathbb R^d$

$$\mathcal F = \{\, x \mapsto \mathrm{sgn}(w \cdot x - \theta) \;:\; w \in \mathbb R^d, \;\theta \in \mathbb R \,\}.$$ Parameters: $(w, \theta)$. Each choice gives a specific linear decision boundary. The class is every such linear classifier.

Example 3: linear regression

$$\mathcal F = \{\, x \mapsto w \cdot x + b \;:\; w \in \mathbb R^d, \;b \in \mathbb R \,\}.$$ Same flavour, real-valued output. Note the language collision: "linear regression" is also the name of the algorithm (least squares fit). The hypothesis class is the set of all linear functions; the algorithm is one recipe for picking one.

Example 4: a neural network with fixed architecture

Fix the layers, widths, and activations. Then $$\mathcal F = \{\, x \mapsto \mathrm{NN}_\theta(x) \;:\; \theta \in \mathbb R^p \,\},$$ where $\theta$ is the vector of all $p$ weights and biases. Each setting of $\theta$ is one specific network. The class is every function you can realise by varying the weights with the architecture held fixed.

Other common classes

  • Polynomials of degree ≤ $k$: $\mathcal F = \{x \mapsto \sum_{i=0}^k a_i x^i : a_i \in \mathbb R\}$.
  • Decision trees of depth ≤ $d$.
  • $k$-nearest-neighbours classifiers (parametrised by which training points are stored).
  • Constant functions: $\mathcal F = \{x \mapsto c : c \in \mathbb R\}$ — the smallest non-trivial class.
Mental model

Picture a box. Inside the box: every linear classifier in $\mathbb R^2$, say. Each is one candidate rule. ERM is "look at the data, pick the function in the box with the highest training accuracy". Generalisation theory asks when is that pick also good on new data? Answer: depends on how big and wiggly the box is. VC dimension and Rademacher complexity are two ways of measuring "how big and wiggly".

Loss function

Definition

A loss function $\ell : \mathcal Y \times \mathcal Y \to \mathbb R_{\ge 0}$ measures how badly a prediction $f(x)$ matches the true label $y$. Larger = worse.

  • 0–1 loss (classification): $\ell(y, y') = \mathbf 1[y \ne y']$. Pays 1 for a wrong answer, 0 for right.
  • Squared loss (regression): $\ell(y, y') = (y - y')^2$.
  • Hinge loss (SVM-style): $\ell(y, y') = \max(0,\, 1 - y y')$ for $y \in \{\pm 1\}$.

Population risk vs empirical risk

Definition

Population risk: $$R(f) = \mathbb E_{(x,y)\sim D}[\ell(y, f(x))]$$ — the loss you'd suffer in expectation over the true data distribution. You can't compute it because you don't know $D$.

Empirical risk: $$\widehat R(f) = \frac{1}{m}\sum_{i=1}^m \ell(y_i, f(x_i))$$ — the average loss on a finite training sample. You can compute this because you have the sample.

The whole game is to use $\widehat R(f)$ (computable) as a proxy for $R(f)$ (the thing you actually care about). The generalisation gap $\widehat R(f) - R(f)$ measures how good a proxy it is.

ERM (Empirical Risk Minimisation)

Definition

The learning recipe "pick the function in $\mathcal F$ that does best on the training sample": $$\widehat f \in \arg\min_{f \in \mathcal F}\, \widehat R(f).$$

ERM is fine if $\widehat R(f) \approx R(f)$ uniformly across $\mathcal F$. If not, ERM overfits — it returns a function that looks great on the sample and bad in reality.

i.i.d. sample

Definition

"Independent and identically distributed". A sample $(x_1, y_1), \dots, (x_m, y_m)$ is i.i.d. if each pair is drawn from the same distribution $D$ and the draws are independent of each other.

This is the standard assumption in statistical learning. Without it, symmetrisation and most concentration arguments break.

Rademacher complexity

Definition

$$\mathfrak{R}_m(\mathcal H) = \mathbb E_{S, \varepsilon}\!\left[\,\sup_{h \in \mathcal H}\, \frac{1}{m}\sum_{i=1}^m \varepsilon_i\, h(z_i)\right]$$ where $\varepsilon_i \in \{\pm 1\}$ are i.i.d. Rademacher (50/50 random signs).

Read it slowly:

  • $\frac{1}{m}\sum \varepsilon_i h(z_i)$ — the correlation between $h$'s outputs and a random sign pattern.
  • $\sup_h$ — pick the single $h$ that lines up best with this particular noise pattern.
  • $\mathbb E$ — average over fresh draws of both data and noise.

So Rademacher complexity is the expected best-case alignment between a function in your class and pure ±1 noise. It is not a count of functions. The intuition "more functions ⇒ higher Rademacher" is only loosely correct; the actual count of label vectors lives in the growth function.

Growth function

Definition

The growth function at sample size $m$ is the worst-case number of distinct label vectors $\mathcal F$ can produce on any $m$ points: $$\Pi_{\mathcal F}(m) = \max_{x_1, \dots, x_m \in \mathcal X}\, \bigl|\,\{(f(x_1), \dots, f(x_m)) : f \in \mathcal F\}\,\bigr|.$$

$\Pi_{\mathcal F}(m) \le 2^m$ always, since there are only $2^m$ possible $\pm 1$ label vectors of length $m$. The growth function is small when $\mathcal F$ is constrained: many functions in the class produce the same label vector on a fixed sample.

Concrete example. Threshold class $\mathcal F = \{x \mapsto \mathrm{sgn}(x-\theta)\}$. On 2 points $x_1 < x_2$, only 3 label vectors are achievable: $(+,+), (-,+), (-,-)$. The vector $(+,-)$ is unrealisable — no threshold can be left of $x_1$ but right of $x_2$. So $\Pi_{\mathcal F}(2) = 3 < 2^2 = 4$.

Shattering

Definition

A set $\{x_1, \dots, x_m\}$ is shattered by $\mathcal F$ if every $\pm 1$ labelling of those points is achievable by some $f \in \mathcal F$. Equivalently, $\Pi_{\mathcal F}(m)$ achieves its max value of $2^m$ on that particular set.

VC dimension

Definition

The Vapnik–Chervonenkis dimension: $$\mathrm{VCdim}(\mathcal F) = \max\{m : \Pi_{\mathcal F}(m) = 2^m\}$$ — equivalently, the size of the largest set that $\mathcal F$ shatters. If $\mathcal F$ shatters arbitrarily large sets, $\mathrm{VCdim}(\mathcal F) = \infty$.

Examples:

  • Thresholds on $\mathbb R$: VCdim = 1.
  • Intervals on $\mathbb R$: VCdim = 2.
  • Axis-aligned rectangles in $\mathbb R^2$: VCdim = 4.
  • Halfspaces in $\mathbb R^d$: VCdim = $d+1$.
  • Convex polygons in $\mathbb R^2$ (no vertex limit): VCdim = $\infty$.

Halfspace

Definition

A halfspace classifier in $\mathbb R^d$ is the function $$f_{w, \theta}(x) = \mathrm{sgn}(w \cdot x - \theta)$$ for $w \in \mathbb R^d$ and $\theta \in \mathbb R$. The decision boundary is the hyperplane $\{x : w \cdot x = \theta\}$; one side is labelled $+1$, the other $-1$.

  • In 1D: halfspace = "everything to the right of $\theta$" (or left). A threshold.
  • In 2D: halfspace = "everything on one side of a line".
  • In 3D: "one side of a plane".
  • In $d$D: "one side of a hyperplane".

Halfspaces are the canonical worked example for VC dim because their VC dim has a clean formula ($d+1$) and short proofs. They also model the perceptron, the linear SVM (without slack), and the decision boundary of logistic regression.

Generalisation gap

Definition

The generalisation gap for a fixed $f$ is $\widehat R(f) - R(f)$. The version that matters for ERM is the supremum over the class: $$\sup_{f \in \mathcal F}\bigl(\widehat R(f) - R(f)\bigr).$$ Bounding this is the goal of uniform convergence theory.

PAC learning

Definition

"Probably Approximately Correct". A class $\mathcal F$ is PAC learnable if there exists an algorithm that, given any $\varepsilon, \delta > 0$ and enough samples, returns a function with population risk at most $\varepsilon$ above the best in $\mathcal F$, with probability at least $1 - \delta$.

For binary classification, PAC learnability is equivalent to finite VC dimension — that's the fundamental theorem of statistical learning.
