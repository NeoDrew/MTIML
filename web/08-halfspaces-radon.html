Chapter 8

Halfspaces have VC dimension d+1

A clean combinatorial result via convex geometry.

The class

Let $\mathcal X = \mathbb R^d$ and consider the class of halfspaces: $$ \mathcal F = \bigl\{\,x \mapsto \mathrm{sgn}(w\cdot x - \theta)\, :\, w\in\mathbb R^d,\ \theta\in\mathbb R\,\bigr\}. $$ Each $f$ is parameterised by a normal vector $w$ and a bias $\theta$. It outputs $+1$ on one side of the hyperplane $\{x : w\cdot x = \theta\}$ and $-1$ on the other.

Theorem 2.1 (Lecture 11)

$\mathrm{VCdim}(\mathcal F) = d + 1.$

To prove this we show two inequalities: $\mathrm{VCdim}(\mathcal F) \ge d + 1$ (some set of size $d+1$ is shattered) and $\mathrm{VCdim}(\mathcal F) \le d + 1$ (no set of size $d+2$ is shattered).

Lower bound: shatter the standard simplex

Take the $d+1$ points $X = \{\mathbf 0, e_1, e_2, \dots, e_d\}$, where $e_i$ is the $i$-th standard basis vector in $\mathbb R^d$. We claim every labelling of these points is realisable by some halfspace.

Proof of lower bound.

Fix any labelling $(b_0, b_1, \dots, b_d) \in \{\pm 1\}^{d+1}$, where $b_0$ is the label at $\mathbf 0$ and $b_i$ is the label at $e_i$. Set $$ \theta = -b_0,\qquad w_i = \theta + b_i = -b_0 + b_i. $$ Then for the origin: $w\cdot \mathbf 0 - \theta = -\theta = b_0$, so $\mathrm{sgn}(w\cdot \mathbf 0 - \theta) = \mathrm{sgn}(b_0) = b_0$. ✓

For the basis vectors: $w \cdot e_i - \theta = w_i - \theta = b_i$, so $\mathrm{sgn}(w\cdot e_i - \theta) = b_i$. ✓

Every labelling is realised, so $X$ is shattered. Since $|X| = d+1$, $\mathrm{VCdim}(\mathcal F) \ge d+1$.

Upper bound: Radon's lemma

For the upper bound — no set of size $d+2$ can be shattered — we need a convex-geometric tool. The right one is Radon's lemma.

Radon's lemma

Let $X = \{x_1, \dots, x_{d+2}\}$ be any $d+2$ points in $\mathbb R^d$. Then there exist disjoint, non-empty $X_1, X_2 \subseteq X$ such that $$ \mathrm{conv}(X_1) \cap \mathrm{conv}(X_2) \ne \emptyset. $$

That is: any $d+2$ points in $\mathbb R^d$ can be partitioned into two parts whose convex hulls intersect.

Four points in $\mathbb R^2$: any way you split them into pairs, the two segments either intersect or are parallel — and at least one such split has a non-empty intersection. Radon's lemma generalises this.

Proof of Radon's lemma

Proof.

Write $X = \{x_1, \dots, x_{d+2}\}$. Consider the system of $d + 1$ linear equations in $d+2$ unknowns $\lambda_1, \dots, \lambda_{d+2}$: $$ \sum_{i=1}^{d+2} \lambda_i x_i = \mathbf 0,\qquad \sum_{i=1}^{d+2} \lambda_i = 0. $$ The first is $d$ equations (one per coordinate of $\mathbb R^d$), and the second is one extra "affine" constraint, giving $d+1$ equations total in $d+2$ unknowns. Underdetermined ⇒ a non-trivial solution $\lambda^* \ne 0$ exists.

Define $$ P = \{i : \lambda^*_i > 0\}, \qquad N = \{j : \lambda^*_j < 0\}. $$ Both are non-empty: $\lambda^* \ne 0$ implies some entry is non-zero, and $\sum \lambda^*_i = 0$ forces both signs to appear.

Let $X_1 = \{x_i : i \in P\}$ and $X_2 = \{x_j : j \in N\}$. We claim that the point $$ z \;=\; \frac{\sum_{i\in P} \lambda^*_i\, x_i}{\sum_{i\in P} \lambda^*_i} \;=\; \frac{\sum_{j\in N} (-\lambda^*_j)\, x_j}{\sum_{j\in N} (-\lambda^*_j)} $$ lies in both convex hulls.

The two equalities follow because $\sum \lambda^*_i x_i = 0$ rearranges to $\sum_{P} \lambda^*_i x_i = \sum_N (-\lambda^*_j) x_j$, and dividing by the (equal, by $\sum \lambda^* = 0$) total weights gives both expressions.

The first expression is a convex combination of $X_1$ (positive weights summing to $1$), so $z \in \mathrm{conv}(X_1)$. The second is a convex combination of $X_2$, so $z \in \mathrm{conv}(X_2)$.

Hence $\mathrm{conv}(X_1) \cap \mathrm{conv}(X_2) \ni z \ne \emptyset$.

Why $d+2$, not $d+1$?

The key system has $d+1$ equations, so we need at least $d+2$ unknowns to guarantee a non-trivial solution. With only $d+1$ points the system might have only the zero solution, and the argument fails. The "+1" comes from the affine constraint $\sum \lambda_i = 0$, which is what forces both $P$ and $N$ to be non-empty — that's the crucial property that lets us split $X$ into two non-empty pieces.

Using Radon to finish the upper bound

Proof of upper bound (no set of size $d+2$ is shattered).

Take any $d+2$ points $X \subseteq \mathbb R^d$. By Radon's lemma, there exist disjoint non-empty $X_1, X_2$ with $\mathrm{conv}(X_1) \cap \mathrm{conv}(X_2) \ne \emptyset$. Pick $z$ in this intersection.

Consider the labelling that assigns $+1$ to all points in $X_1$ and $-1$ to all points in $X_2$. Suppose, for contradiction, that some halfspace $H = \{x : w\cdot x \ge \theta\}$ realises this labelling.

Then $w \cdot x \ge \theta$ for every $x \in X_1$. Since $z$ is a convex combination of points in $X_1$, by linearity $w \cdot z \ge \theta$, so $z$ would be labelled $+1$ by $H$.

But the same argument, applied to $X_2$, shows $w \cdot z < \theta$, so $z$ would be labelled $-1$. Contradiction.

No halfspace realises this labelling, so $X$ is not shattered. Hence $\mathrm{VCdim}(\mathcal F) \le d+1$.

Combined with the lower bound, $\mathrm{VCdim}(\mathcal F) = d + 1$.

A more general result

The same proof technique generalises to any class of the form $\mathcal F = \{\mathrm{sgn} \circ g : g \in \mathcal G\}$ where $\mathcal G$ is a finite-dimensional vector space of functions.

Theorem 2.2

If $\mathcal G$ is a vector space of functions $\mathbb R^d \to \mathbb R$ with $\dim(\mathcal G) = k$, and $\mathcal F = \{\mathrm{sgn}\circ g : g \in \mathcal G\}$, then $$ \mathrm{VCdim}(\mathcal F) \le k. $$

Halfspaces correspond to $\mathcal G = \mathrm{span}\{1, x_1, \dots, x_d\}$ — affine functions in $d$ variables — with $\dim(\mathcal G) = d+1$, recovering Theorem 2.1.

The proof uses the same idea: the evaluation map $T(g) = (g(x_1), \dots, g(x_{k+1}))$ has image of dimension at most $k$ in $\mathbb R^{k+1}$, so some non-zero $\lambda$ is orthogonal to it. Splitting $\lambda$ into positive and negative parts mimics the $P/N$ argument of Radon's proof. The labelling that's $+1$ on $P$ and $-1$ on $N$ is unrealisable.

What's next

We have a class with VC dimension $d+1$. The Rademacher bound says $\mathfrak R_m(\mathcal F) \le \sqrt{2\ln \Pi_{\mathcal F}(m) / m}$, but we still need to know how $\Pi_{\mathcal F}(m)$ behaves once $m > d+1$. Sauer's lemma will tell us: it's at most polynomial in $m$.
