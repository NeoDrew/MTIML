Section 5

VC Dimension

Shattering, definition, examples, and the halfspace bound.

Shattering and VC dimension

A set $\{x_1, \dots, x_m\}$ is shattered by $\mathcal F$ if $$\mathcal F\big|_{x_1^m} = \{\pm 1\}^m,$$ that is, every binary labelling is realised by some $f \in \mathcal F$.

Vapnik–Chervonenkis dimension

The supremum of cardinalities shattered by $\mathcal F$: $$\mathrm{VCdim}(\mathcal F) \;=\; \sup\{m : \Pi_{\mathcal F}(m) = 2^m\}.$$ If $\mathcal F$ shatters arbitrarily large sets, $\mathrm{VCdim}(\mathcal F) = \infty$.

Examples

$\mathcal X$$\mathcal F$$\mathrm{VCdim}(\mathcal F)$
$\mathbb R^2$convex polygons$\infty$
$\mathbb R^2$axis-aligned rectangles$4$
$\mathbb R^2$convex polygons with $d$ vertices$2d + 1$
$\mathbb R^d$halfspaces$d + 1$

Halfspaces in $\mathbb R^d$

Define $\mathcal F = \{x \mapsto \mathrm{sgn}(w \cdot x - \theta) : w \in \mathbb R^d, \theta \in \mathbb R\}$. We claim $\mathrm{VCdim}(\mathcal F) = d + 1$.

Lower bound: shatter $\{\mathbf 0, e_1, \dots, e_d\}$

Proof of lower bound.

Take the $d+1$ points $X = \{\mathbf 0, e_1, \dots, e_d\}$. Given any labelling $(b_0, b_1, \dots, b_d) \in \{\pm 1\}^{d+1}$, set $$\theta = -b_0,\qquad w_i = \theta + b_i.$$ Check: $w \cdot \mathbf 0 - \theta = -\theta = b_0$, and $w \cdot e_i - \theta = w_i - \theta = b_i$. Every labelling is realised, so $X$ is shattered.

$\mathrm{VCdim}(\mathcal F) \ge d + 1.$

Upper bound: Radon's lemma

Radon's lemma

Any $d + 2$ points in $\mathbb R^d$ admit a partition $X_1, X_2$ with $$\mathrm{conv}(X_1) \cap \mathrm{conv}(X_2) \ne \emptyset.$$

The labelling assigning $+1$ to $X_1$ and $-1$ to $X_2$ then cannot be realised by any halfspace, since a halfspace assigning a label to a set assigns the same label to its convex hull — both sides would force the intersection point to receive opposite labels.

Proof of Radon's lemma.

For $X = \{x_1, \dots, x_{d+2}\}$, consider the system of $d+1$ equations in $d+2$ unknowns: $$\sum_{i=1}^{d+2} \lambda_i x_i = \mathbf 0,\qquad \sum_{i=1}^{d+2} \lambda_i = 0.$$ Underdetermined ⇒ a non-trivial solution $\lambda^* \ne 0$ exists. Let $P = \{i : \lambda^*_i > 0\}$, $N = \{j : \lambda^*_j < 0\}$. Both are non-empty (since $\sum \lambda^*_i = 0$).

The point $$z \;=\; \frac{\sum_{i\in P}\lambda^*_i x_i}{\sum_{i\in P}\lambda^*_i} \;=\; \frac{\sum_{j\in N}(-\lambda^*_j) x_j}{\sum_{j\in N}(-\lambda^*_j)}$$ is a convex combination of both $X_1 = \{x_i : i \in P\}$ and $X_2 = \{x_j : j \in N\}$, so it lies in both convex hulls.

Four points in $\mathbb R^2$: Radon's lemma guarantees a partition whose convex hulls intersect.
