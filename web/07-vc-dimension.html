Chapter 7

VC dimension

The largest set on which the class can do anything.

Shattering

Definition — shattering

A set of points $\{x_1, \dots, x_m\} \subseteq \mathcal X$ is shattered by $\mathcal F$ if every possible $\pm 1$ labelling of those points is realised by some $f \in \mathcal F$: $$ \mathcal F\big|_{x_1^m} = \{\pm 1\}^m. $$ Equivalently, for every labelling $b = (b_1, \dots, b_m) \in \{\pm 1\}^m$, there exists $f\in\mathcal F$ with $f(x_i) = b_i$ for every $i$.

Shattering is a strong condition. On $m$ points, there are $2^m$ possible labellings; shattering means $\mathcal F$ is rich enough to produce every single one of them. The growth function reaches its maximum: $\Pi_{\mathcal F}(m) = 2^m$ if and only if some $m$-element set is shattered.

Two points are shattered by $\mathcal F$ if all four labellings can be realised by some $f \in \mathcal F$.

The VC dimension

Definition — Vapnik–Chervonenkis dimension

The VC dimension of $\mathcal F$ is the size of the largest set shattered by $\mathcal F$: $$ \mathrm{VCdim}(\mathcal F) \;=\; \max\bigl\{m : \Pi_{\mathcal F}(m) = 2^m\bigr\}. $$ If $\Pi_{\mathcal F}(m) = 2^m$ for all $m$, we say $\mathrm{VCdim}(\mathcal F) = \infty$.

Read it twice. The VC dimension is the largest $m$ such that there exists a set of size $m$ that the class shatters. It is enough that some set of size $m$ is shattered — not every one. To prove $\mathrm{VCdim}(\mathcal F) \ge d$, you exhibit one $d$-point set the class shatters. To prove $\mathrm{VCdim}(\mathcal F) \le d$, you show that every $(d+1)$-point set fails to be shattered.

Two halves of the VC dimension

Lower bound ($\ge d$): exhibit some $d$-point set and show every labelling of it is realised. Constructive.

Upper bound ($\le d$): show every $(d+1)$-point set has at least one unrealisable labelling. Universal.

Worked example: thresholds have VC dimension 1

Class: $\mathcal F = \{f_\theta : \theta \in \mathbb R\}$ with $f_\theta(x) = \mathrm{sgn}(x - \theta)$.

Lower bound ($\ge 1$). Pick any single point $x_1$. The two labellings $(+1)$ and $(-1)$ are both achievable: take $\theta < x_1$ for $+1$, $\theta > x_1$ for $-1$. Done.

Upper bound ($\le 1$). Take any two points $x_1 < x_2$. The labelling $(+1, -1)$ requires $f(x_1) = +1$ (so $\theta < x_1$) and $f(x_2) = -1$ (so $\theta > x_2$), but $x_1 < x_2$ makes this impossible. So no two-point set is shattered.

Combining: $\mathrm{VCdim}(\mathcal F) = 1$.

Worked example: intervals have VC dimension 2

Class: $\mathcal F = \{f_{a,b} : a < b\}$ with $f_{a,b}(x) = +1$ if $a \le x \le b$, else $-1$.

Lower bound. Pick $x_1 < x_2$. All four labellings are realised: $(-,-)$ by an interval far away; $(+,+)$ by an interval covering both; $(+,-)$ by an interval $[x_1, x_1{+}\tfrac{x_2-x_1}{2}]$; $(-,+)$ symmetrically. So 2-point sets are shattered.

Upper bound. Take any three points $x_1 < x_2 < x_3$. The labelling $(+, -, +)$ is impossible: any interval containing both $x_1$ and $x_3$ also contains $x_2$.

Worked example: rectangles in the plane have VC dimension 4

Class: axis-aligned rectangles. Members are functions $f_{R}(x) = +1$ if $x\in R$, $-1$ otherwise.

Lower bound ($\ge 4$). Pick four points: leftmost, rightmost, topmost, bottommost (no two coordinate-aligned). For any labelling, draw a rectangle that exactly contains the points labelled $+1$ — its edges aligned with the chosen extremes. Sketch:

Four extremal points. Any subset can be enclosed by a rectangle that excludes the others.

Upper bound ($\le 4$). For any 5 points, one is "interior" to the others (it isn't extremal in any of the 4 coordinate directions). Label that point $-1$ and the other four $+1$. The minimal rectangle containing the four $+$s also contains the $-$, so that labelling is not realisable.

Why VC dimension is the right number

VC dimension is the threshold past which the trivial bound $\Pi_{\mathcal F}(m) \le 2^m$ becomes loose. For $m \le \mathrm{VCdim}(\mathcal F)$, the class can shatter, so $\Pi_{\mathcal F}(m) = 2^m$. For $m$ just past the VC dim, the bound starts to fail — and Sauer's lemma will tell us by how much.

What's next
